Execution Modes

Live bridge when local, clipboard commands when offline

When PWA Studio connects to /api/factory, tapping a card button runs the shell script or launches tmux + Pi Agent directly. When opened offline as a standalone PWA, the same button copies the exact shell command to the Android clipboard.
